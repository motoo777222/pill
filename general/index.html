今天要吃的药

准时响铃提醒

网页没法自己响铃。把吃药时间加进手机日历，到点由日历发通知、响铃、震动。改了设置要重新加一次。
到点没响？看这里
  1. 保存前看顶部：要选“活动”，不要选“任务”（任务前面带 ✓ 圈，不能设响铃通知）。
  2. 谷歌日历保存前：看顶部的账号，要选手机日历正在用的那个账号；点铃铛 🔔 那一行（写着“提前 10 分钟”“提前 30 分钟”之类），改成“活动开始时”，提醒就会准点响，不会提前。
  3. 保存后：在日历里点开那条吃药提醒，看铃铛那一行写的是“活动开始时”还是“提前 X 分钟”。
  4. 手机设置 → 应用 → 日历 → 通知：打开“允许通知”，“活动提醒”这一项打开声音和振动。
  5. 勿扰模式会把提醒静音；电池设置里把日历设成“不限制”。
  6. 网页弹窗只在本页正显示在屏幕上时才出现，切到后台就不会弹，不能代替日历。
能用手机“时钟”闹钟吗？
  1. 网页不能自动帮你建闹钟，日历提醒也不会出现在时钟里。
  2. 每天吃的药：可以在时钟里手动新建闹钟，重复选“每天”。
  3. 隔天吃的药：时钟只能按星期几重复，做不到隔天，请用日历提醒。
怎么清空日历里的吃药提醒
  1. 谷歌日历：点开任意一条“吃药：…” → 删除（垃圾桶或 ⋮ 菜单）→ 选“所有活动”（如果存成了任务，就选“所有任务”）。
  2. 每个时间点是单独一组，比如 08:00 和 20:00，要各删一次；没有一键全清。
  3. 苹果日历：点开那条日程 → 删除日程 → “删除所有将来日程”。
  4. 删完后点本页的“清除已设置标记”。

放到手机桌面

  1. 用 Chrome、Edge、Brave、Firefox 或 Safari 打开本页
  2. 点浏览器菜单（⋮ 或 分享按钮）
  3. 选“添加到主屏幕”

重新开始

药吃完了、换药了，或想从头来过：清空设置和打卡记录，回到刚打开时的样子。
确定全部重置吗？清空后不能找回。
